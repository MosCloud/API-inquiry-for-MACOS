# v0.3.15 Release Implementation Plan

> **For agentic workers:** Execute this release plan inline with verification gates. Do not publish a release without fresh evidence for every gate.

**Goal:** Publish API Inquiry v0.3.15 from the verified `v0.3.15` feature branch as a GitHub Release with a validated DMG and checksum.

**Architecture:** Prepare tracked release metadata and user-facing documentation on the feature branch, merge that verified branch into local `main`, then package from merged `main`. The physical `dist` app may receive Desktop/FileProvider metadata after copying, so release acceptance is the app mounted from the final DMG.

**Tech Stack:** Swift Package Manager, macOS `codesign`, `hdiutil`, `shasum`, Git, GitHub CLI.

- Work in `/Users/zbw/Desktop/API-inquiry/.worktrees/v0.3.15` until the verified fast-forward merge; package and publish from `/Users/zbw/Desktop/API-inquiry` on `main`.
- Use `swift run APIInquiryCoreTestsRunner`, never `swift test`; the release candidate must report `PASS: 679 expectations`.
- Use fake/mocked tests only; never print credentials, access tokens, account ids, or authenticated response bodies.
- Preserve the root worktree's pre-existing untracked `AGENTS.md`, `CLAUDE.md`, and `docs/reviews/` content. Do not modify, copy, stage, commit, or delete those files.
- Credits are raw `credits.balance` usage units from the existing `/backend-api/wham/usage` response. Do not add an endpoint, perform currency conversion, or reuse the manual-reset credits subsystem.
- Only the OpenAI/Codex Console Home `Status` metric is replaced. Keep the top status badge, quota `Detail`, Menubar output, detail-sheet structure, geometry, corners, material, opacity, and transparency unchanged. Other providers retain `Status`.
- Missing, malformed, or negative Credits display `--`; valid 5h/1W quota data remains usable when Credits is invalid. `credits.unlimited == true` displays localized Unlimited even if balance is malformed.
- Do not publish if the final mounted DMG app fails `codesign --verify --deep --strict`.
- The GitHub Release must be non-draft and non-prerelease and contain exactly the DMG and its `.sha256` file.
