# v0.3.14 Release Implementation Plan

> **For agentic workers:** Execute this release plan inline with verification gates. Do not publish a release without fresh evidence for every gate.

**Goal:** Publish API Inquiry v0.3.14 from the verified `v0.3.14` feature branch as a GitHub Release with a validated DMG and checksum.

**Architecture:** Prepare all tracked release metadata on the feature branch, merge that verified commit into local `main`, then package from `main`. The physical `dist` app may receive Desktop/FileProvider metadata after copying, so release acceptance is the app mounted from the final DMG, not a delayed verification of `dist/API Inquiry.app`.

**Tech Stack:** Swift Package Manager, macOS `codesign`, `hdiutil`, `shasum`, Git, GitHub CLI.

## Global Constraints

- Release version is `0.3.14`, build number is `19`, and tag is `release/v0.3.14`.
- Use `swift run APIInquiryCoreTestsRunner`, never `swift test`.
- Use fake/mocked tests only; never print credentials or Codex auth payloads.
- Preserve the root worktree's pre-existing untracked `AGENTS.md`, `CLAUDE.md`, and `docs/reviews/` content.
- Do not publish if the final mounted DMG app fails `codesign --verify --deep --strict`.
- GitHub Release is non-draft and non-prerelease and uploads exactly the DMG and its `.sha256` file.
