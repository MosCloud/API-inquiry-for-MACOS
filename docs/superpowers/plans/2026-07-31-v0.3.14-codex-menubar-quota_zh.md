# API Inquiry v0.3.14 Codex Menubar 额度精简实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** Menubar 只显示选中的 Codex 剩余额度百分比，同时在点击后的详情中完整保留 5 小时和周额度信息。

**架构：** 保持现有语义窗口选择器和全部详情行路径不变。将行为修改限制在 `ProviderValueFormatter.menuQuotaWindowText(for:)`：已识别的 5 小时和周窗口只显示百分比；使用 `MenuBarBalanceViewModelTests` 覆盖双窗口、仅周窗口、本地化、供应商到 Menubar 的集成路径及其他供应商无回归。

**技术栈：** Swift 5.9 package manifest、SwiftUI/AppKit macOS 应用、`APIInquiryCore`、自定义可执行测试 Runner `APIInquiryCoreTestsRunner`、模拟 `HTTPClient`、Git worktree。

private static func menuQuotaWindowText(for window: QuotaWindowSnapshot?) -> String {
