# API Inquiry v0.4.2

## Bug Fixes

- **"Next expiry" no longer shows a date that has already passed**: WorkBuddy keeps returning promotional packages that have already lapsed, and their expiry was being read as the next one to lose credits, so the card could show a date from the past. Only what still holds credits and has not expired counts now, and the date matches what WorkBuddy's own page shows.

## Download verification

```bash
shasum -a 256 -c API-Inquiry-v0.4.2.dmg.sha256
```

## Known Limitations

- Apple notarization is not enabled yet; the first launch may need approval in System Settings → Privacy & Security.
- WorkBuddy is still CN-region only, and needs the desktop app installed and signed in.
