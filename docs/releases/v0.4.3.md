# API Inquiry v0.4.3

## New Features

- **Refresh from the Console**: Home now has a Refresh button that updates every provider at once, including the Codex manual-reset credits — no waiting for the automatic refresh and no trip back to the menu bar.
- **Arrange providers the way you work**: drag a card by the handle in its bottom-right corner. The other cards make room as you move, the list scrolls when you reach the top or bottom edge, and the order is remembered. Right-clicking a card also offers Move Up / Move Down.

## App Optimization

- **A new install window**: the installer has been redrawn and now comes in two languages — download the Chinese or the English one and the window matches, while the app inside is the same.
- **The menu bar panel follows the Console order**: whatever order you set on Home also applies to the secondary providers in the panel.

## Bug Fixes

- **The scrollbar no longer covers provider cards**: while the Console list scrolls, the scroller stays in the window margin instead of running over badges and figures.

## Download verification

```bash
shasum -a 256 -c API-Inquiry-v0.4.3.dmg.sha256
```

## Known Limitations

- Apple notarization is not enabled yet; the first launch may need approval in System Settings → Privacy & Security.
- WorkBuddy is still CN-region only, and needs the desktop app installed and signed in.
