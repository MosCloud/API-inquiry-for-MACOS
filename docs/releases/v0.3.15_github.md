# API Inquiry v0.3.15

## 中文

### New Features

- Console Home 的 OpenAI/Codex 卡片以 `Credits 余额` 显示现有 usage 响应中的原始 Credits 余额，使用 `Credits` 单位，不进行货币换算。
- 明确的零值显示为 `0 Credits`；无限额度显示本地化的 `无限`。

### App Optimization

- Credits 缺失、异常或无效时显示 `--`，同时保留有效的 5h/1W quota `Detail`、顶部状态徽章和 manual-reset 信息；其他供应商继续显示 `Status`。

### 下载校验

```bash
shasum -a 256 -c API-Inquiry-v0.3.15.dmg.sha256
```

### 已知限制

- Apple notarization 尚未启用。
- Codex quota 与 manual-reset 信息依赖本机 Codex/ChatGPT 凭据；如果凭据过期，需要先刷新登录态再查询。
- Credits 显示的是原始 Credits 用量单位，不代表货币金额。

---

## English

### New Features

- The OpenAI/Codex card on Console Home now shows the raw Credits balance from the existing usage response as `Credits balance`, with a `Credits` unit and no currency conversion.
- An explicit zero is shown as `0 Credits`; unlimited credits use the localized `Unlimited` label.

### App Optimization

- Missing, malformed, or invalid Credits show `--` while valid 5h/1W quota `Detail`, the top status badge, and manual-reset information remain available; other providers continue to show `Status`.

### Verify Downloads

```bash
shasum -a 256 -c API-Inquiry-v0.3.15.dmg.sha256
```

### Known Limitations

- Apple notarization is not enabled.
- Codex quota and manual-reset information depend on the local Codex/ChatGPT credentials. If those credentials expire, refresh the login before querying again.
- The Credits value is a raw usage-unit balance, not a currency amount.
