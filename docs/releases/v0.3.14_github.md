# API Inquiry v0.3.14

## 中文

### 新功能

- OpenAI/Codex 的 Menubar 额度现在仅显示剩余百分比：存在 5 小时窗口时显示该窗口额度；仅返回周额度时显示周额度。
- 点击 Menubar 后可查看查询结果中全部已识别额度窗口的剩余百分比与重置时间。

### 应用优化

- 提升当前 macOS 上菜单栏面板的原生外观一致性，使圆角与材质效果保持稳定。

### 问题修复

- 修复 OpenAI/Codex 仅返回周额度时的识别与展示，避免因缺少 5 小时窗口而显示异常。

### 下载校验

```bash
shasum -a 256 -c API-Inquiry-v0.3.14.dmg.sha256
```

### 已知限制

- Apple notarization 尚未启用。
- 手动重置额度依赖当前本机 Codex/ChatGPT 凭证；如果凭证过期，需要先刷新登录态再查询。

## English

### New Features

- OpenAI/Codex quota in the menu bar now shows only the remaining percentage: it uses the five-hour window when available, and the weekly window when that is the only returned quota.
- Clicking the menu bar item now shows the remaining percentage and reset time for every recognized quota window returned by the query.

### App Optimization

- Improved native menu-bar panel rendering consistency on current macOS so the corner and material appearance remains stable.

### Bug Fixes

- Fixed OpenAI/Codex weekly-only quota recognition and display when the upstream response does not include a five-hour window.

### Verify Downloads

```bash
shasum -a 256 -c API-Inquiry-v0.3.14.dmg.sha256
```

### Known Limitations

- Apple notarization is not enabled.
- Manual reset credits depend on the current local Codex/ChatGPT credentials. If those credentials expire, refresh the login before querying again.
