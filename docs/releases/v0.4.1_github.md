# API Inquiry v0.4.1

## 中文

### 新增功能

- **支持 WorkBuddy**：菜单栏和 Console 都能查看 WorkBuddy 的剩余积分，Console 的 API 页可以直接打开 WorkBuddy 的配置文件。使用本机 WorkBuddy 桌面端的登录状态，不需要另外填密钥。
- **积分分成三类说清楚**：卡片把「总积分」和「赠送积分」分开显示，各自带上对应的日期——总积分显示下次刷新的时间，赠送积分显示最近到期的时间，快过期的奖励不会再被混在一个总数里。

### 应用优化

- **积分用的是自己的单位**：WorkBuddy 的积分不是金额，界面显示为「积分」而不是货币符号，中文和英文界面都是本地化措辞。
- **日期不再挤在数字后面**：菜单栏面板的副行只放单位，日期改到 Console 里单独一行显示，带「下次刷新」「最近到期」字样，不会和数字连在一起读成分数。

### 已知限制

- WorkBuddy 目前只支持**国内版**（www.codebuddy.cn），国际版还不能用。
- 需要本机安装 WorkBuddy 桌面端并保持登录：它从 5.6.0 起把凭据加密存放，只有桌面端能解开。读不出来时 Console 会明确提示，而不是笼统地说「未配置」。
- 只读展示：不签到、不领奖励、不切换账号，也不会改动 WorkBuddy 自己的登录凭据。


## English

### New Features

- **WorkBuddy support**: the menu bar and Console both show WorkBuddy's remaining credits, and the Console API page can open WorkBuddy's own config file. It uses the desktop app's existing sign-in — there is no key to paste.
- **Credits, split into the two things they are**: the card separates "total credits" from "granted credits" and dates each one — the total shows when it next refreshes, the granted figure shows when the nearest reward expires, so rewards about to lapse no longer hide inside one big number.

### App Optimization

- **Credits are their own unit**: WorkBuddy's credits are not money, so the UI says 积分 / credits instead of putting a currency symbol in front of them.
- **Dates moved out of the number's shadow**: the menu bar panel's secondary row now carries only the unit; the dates moved to the Console on their own line, prefixed with "refreshes" and "expires" so they cannot be read as a fraction.

### Known Limitations

- WorkBuddy is **CN-region only** (www.codebuddy.cn) for now; the international build is not supported yet.
- The WorkBuddy desktop app must be installed and signed in: since 5.6.0 it stores its credential encrypted, and only the app can unlock it. When the credential cannot be read, the Console says so plainly instead of reporting the provider as unconfigured.
- Read-only: it never checks in, claims rewards, switches accounts, or writes to WorkBuddy's own sign-in.
