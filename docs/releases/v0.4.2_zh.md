# API Inquiry v0.4.2

## 问题修复

- **「最近到期」不再显示已经过去的日期**：WorkBuddy 会把已经失效的赠送包一起返回，它的到期时间被当成了「下一次到期」，于是卡片上出现一个早就过去的日期。现在只有还留着积分、且尚未到期的部分才参与，显示的日期与 WorkBuddy 自己的界面一致。

## 下载校验

```bash
shasum -a 256 -c API-Inquiry-v0.4.2.dmg.sha256
```

## 已知限制

- Apple notarization 尚未启用，首次打开可能需要在「系统设置 → 隐私与安全性」里放行。
- WorkBuddy 仍只支持国内版；使用本机桌面端的登录态，需要安装并保持登录。
