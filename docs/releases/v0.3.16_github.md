# API Inquiry v0.3.16

## 中文

### Bug Fixes

- 修复 Console Home 的 OpenAI/Codex 卡片把 Credits 余额的完整小数位原样显示的问题：`64999.557415` 这类长小数现在最多显示两位（`64999.55`），不再看起来像浮点误差。

## English

### Bug Fixes

- Fixed the OpenAI/Codex card on Console Home showing the full fractional Credits balance: long values such as `64999.557415` now display at most two decimals (`64999.55`) instead of looking like a floating point error.
- The displayed value is truncated, never rounded up, so the shown balance can never exceed the credits actually left. Whole balances stay as they are (`65000` still reads `65000 Credits`, not `65000.00`).
- Missing, malformed, or negative Credits still show `--`, unlimited credits still use the localized `Unlimited` label, and the 5h/1W quota detail and top status badge are unchanged.

### Verify Downloads

```bash
shasum -a 256 -c API-Inquiry-v0.3.16.dmg.sha256
```

### Known Limitations

- Apple notarization is not enabled.
- Codex quota and manual-reset information depend on the local Codex/ChatGPT credentials. If those credentials expire, refresh the login before querying again.
- The Credits value is a raw usage-unit balance, not a currency amount; it is displayed with at most two decimals while the real balance is more precise.
