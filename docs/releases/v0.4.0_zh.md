# API Inquiry v0.4.0

## 新增功能

- **支持 OpenCode**：菜单栏和 Console 都能查看 OpenCode 的用量（5 小时 / 每周 / 每月），Console 的 API 页可以直接打开 OpenCode 的配置文件。
- **DeepSeek 赠送余额**：DeepSeek 卡片新增「赠送余额」，原来的「详情」改名为「总余额」，赠送与充值的金额分开显示，不再混在一起。
- **刷新失败会标记**：某次刷新失败后，菜单栏的数字会带上过期标记，不会再把旧数据当成最新结果。
- **复制版本信息**：点击 Console 里的版本号即可复制当前构建的提交号，反馈问题时不用手动抄。

## 应用优化

- **面板更紧凑**：主区只保留当前窗口，其余窗口收成一行摘要；面板高度减少约 18%，信息一条没少。
- **三列对齐**：所有次要供应商统一为「窗口 / 剩余 / 重置时间」三列；余额型供应商的金额、币种也对到同样的位置。列宽随内容自动收缩，不再固定预留。
- **字号统一**：数值与标签的字号、字重统一，数字不再一大一小；供应商名字过长时只让名字让步，数字始终保持原大小。
- **状态更准确**：状态文案按供应商实际售卖方式区分——订阅制显示「计划可用 / 计划已用尽」，预付费显示「可用 / 余额不足」，不再用同一套说法。
- **刷新更可靠**：连续点击刷新或保存 Key 时，刷新请求会合并处理而不是被丢弃，界面不会停在旧数据。
- **细节统一**：智谱在菜单栏只显示百分比，标签补齐中英文；警告色与其他供应商一致；各家 logo 按同一视觉基准缩放，四个字标看起来终于一样大。

## 问题修复

- 移除 Console 首页智谱卡片上多出来的「计划下次重置」空列。
- 修复缺少供应商图片时应用启动崩溃的问题。
- 修复 OpenCode 接入后 Codex 的本地配置提示消失的问题。
- 修复 Codex / OpenCode 凭据失效时，提示不指向各自 CLI 的问题。

## 已知限制

- Apple notarization 尚未启用，首次打开可能需要在「系统设置 → 隐私与安全性」里允许。

- DeepSeek 的「赠送余额」只在接口返回该字段时显示。
